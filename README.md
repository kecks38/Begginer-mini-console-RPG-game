# Мини-RPG на Python

Консольная пошаговая боёвка между героем и врагом. Учебный проект на Python с использованием ООП.

## Возможности

- Класс `Character` с именем, здоровьем (HP), максимальным HP и диапазоном атаки
- Атака со случайным уроном в заданном диапазоне (`random.randint`)
- Шанс критического удара (урон x2)
- Лечение зельем: восстанавливает случайное количество ОЗ, не превышая максимум
- Ограниченное количество зелий лечения за бой (3 штуки)
- Проверка, жив ли персонаж
- Пошаговый цикл боя: герой действует, враг отвечает
- Выбор действия в свой ход: удар, зелье или сдаться
- Определение победителя по итогам боя (победа, поражение или сдача)
- Обработка некорректного ввода при выборе действия

## Как запустить

\`\`\`bash
python MINI-RPG.py
\`\`\`

После запуска в консоли начнётся бой. На каждом ходу нужно выбрать действие:
1. Удар
2. Зелье (восстановить ОЗ)
3. Сдаться

## Технологии

- Python 3
- ООП: классы, методы, атрибуты объекта
- Модуль `random` для случайного урона, крита и лечения
- `try` / `except` для обработки ошибок ввода
