# Мини-RPG на Python

Консольная пошаговая боёвка между героем и врагом. Учебный проект на Python с использованием ООП.

## Возможности

- Класс `Character` с именем, здоровьем (HP) и диапазоном атаки
- Атака со случайным уроном в заданном диапазоне (`random.randint`)
- Проверка, жив ли персонаж
- Пошаговый цикл боя: герой атакует, враг отвечает
- Выбор действия в свой ход: атаковать или сдаться
- Определение победителя по итогам боя (победа, поражение или сдача)
- Обработка некорректного ввода при выборе действия

## Как запустить

\`\`\`bash
python MINI-RPG.py
\`\`\`

После запуска в консоли начнётся бой. На каждом ходу нужно выбрать действие:
1. Удар
2. Сдаться

## Технологии

- Python 3
- ООП: классы, методы, атрибуты объекта
- Модуль `random` для случайного урона
- `try` / `except` для обработки ошибок ввода
